# 錬金工房II・IIIの段階別アート (0.6.95)

錬金工房Iの元画像を維持し、IIに低い作業別棟と追加の銅製蒸留器、IIIに高い主棟・石造りのサービス棟と大きな蒸留設備を持つ専用画像を追加しました。青緑の屋根、木組み、漆喰、薬草、暖色の窓を既存の画風へ合わせています。画像の縦横比を保ち、拠点の表示範囲をII48×47px、III52×51pxに制限しています。

組込み画像生成を各段階1回使用。原PNGを永続保存し、読戻し・SHA256・全デコード・PNG CRC・透過・目視を確認して、原bytesのまま製品へコピーしました。プロンプト、bytes、寸法、SHA256、制作方式は `assets/pixel-v2/ARTWORK-PROVENANCE.json` の `laboratoryStagesII_III` に記録しています。第三者の画像や新しいライブラリは導入していません。

拠点とカードで同じ段階選択を使います。II/III画像が失敗した場合はIの元画像へ、Iも失敗した場合は瓶と蒸留器・段階印の軽量なSVGへ切り替えます。各段階の失敗は独立し、更新ごとの再試行はしません。代替図を専用アートの制作完了数へ含めていません。炊事場・住宅の完成済み画像と表示分岐は回帰確認対象です。

合成データと隔離したPC Chromeで、1280/390/320幅、通常／動きを減らす設定、拠点と建築カード、各段階の本体差分、画像欠損4条件、有償I→II/II→IIIと保存再読込、実際の最大段階で全施設を建てた画面を確認します。スクロール・予約編集・倍率・フォーカス・再読込の回帰も対象です。実機スマホや人間の長時間プレイを検証したとは扱いません。

ゲームの費用・時間・施設効果・戦闘・経済・報酬・保存形式は変更していません。他の専門施設（仕事場・弓術場・魔術研究所）のII/III、地域別拠点13種類、非鉄系防具の専用アートは未対応のままです。
