# リプレイ実績（0.6.90）

初達成クエスト／継承ポイントとは別の、報酬なしの収集記録。通常36波が対象で、エンドレスや旧21/24波のクリアでは解除しない。設定の「実績・挑戦条件を見る」、焚き火の記録、36波のクリア画面で確認できる。

| 安定ID | 条件 |
| --- | --- |
| frontier_clear | 通常36波をクリア。既存の firstFrontierClear も根拠として利用 |
| frontier_15_generations | 新しい挑戦の第15世代以内に通常36波をクリア |
| frontier_martial | 武勇の追加集だけを購入し、有効にして3世代以上を開始、弓術場IIを一度建設、集を有効にしてクリア |
| frontier_fortress | 上と同様に要塞の追加集、錬金工房II |
| frontier_economy | 上と同様に経済の追加集、仕事場II |
| frontier_without_towers | 全世代で弓塔・衛兵所の建設を開始せずクリア。仲間・柵・継承は可 |
| frontier_without_market | 全世代で市場の建設を開始せずクリア。行商人・外交・継承は可 |

短世代と縛りは独立条件。縛りに世代上限はない。タイプ判定は最後の装備だけでは決めない。通常の継承強化は制限しない。他タイプの追加集を購入／確定した履歴は振り直し後も残すが、配分案の中で買って取消しただけなら購入とは数えない。3世代という条件は、解放時期が遅い要塞の集を含めた成立確認から選定。15世代は攻略課題であり、最適解／全プレイヤーのクリア目標ではない。

## 保存と新しい挑戦

任意の `replay` フィールド（version 1）に、解除済みコレクションと現在の挑戦の履歴を分離。挑戦IDは新規開始時に生成し、転生では維持する。`recordReplayClear` の戻り値がプラットフォーム非依存の解除イベント境界。Steam APIや認証は利用せず、将来のSteam互換も保証しない。

「新しい挑戦」は確認画面とチェックの後に明示実行。進行・継承は第1世代へ戻り、解除済み実績は引き継ぐ。直前の挑戦のバックアップを保持。保存に失敗したら現在の進行を差し替えない。

インポート／バックアップ復元時は解除済み実績を和集合で保持。挑戦IDが同じなら既に開始した禁止建設、購入した集、クリア完了の履歴も保持する。過去の保存へ戻して制限履歴だけを消せない。世代数を並行スナップショットから加算しない。別の挑戦の履歴を混ぜない。JSON手動編集に対する不正防止機構ではない。

旧データは通常36波の既存クリア記録だけを遡及授与。タイプ・世代・縛りを推測しない。旧データの進行や資産は保持し、条件履歴を必要とする実績は新しい挑戦から記録する。解除記録を含めて書き出し／読み込みできる。ブラウザの保存そのものを消去した場合に備えて書き出しを利用する。

## 検証と限界

資源・XP・敵・報酬を付与しない既存の固定攻略に、アクセサリー準備方針を使用。抽選seedだけを固定。武勇seed1（市場・弓塔・衛兵所なし）、経済seed1、要塞seed1は各14世代、武勇seed2（弓塔・衛兵所なし）は15世代で36波をクリア。全7条件の解除を確認。単一の人間のプレイ再現、最適世代数、主観的な難易度の保証ではない。

武勇seed1の同条件0.6.89比較では、全世代の資源・報酬・戦闘・所要時間・行動列が一致。最終保存も既存ローダーの正規化と追加実績フィールドを除いて一致。難易度、報酬、ゲーム速度、既存装備や初達成クエストは変更していない。

ブラウザは隔離データでPC/390px/320pxを検証。実機iOS/Android、Steam、実ユーザーセーブの検証は含まない。
