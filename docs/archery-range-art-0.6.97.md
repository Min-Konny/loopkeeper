# 弓術場II・IIIの段階別アート (0.6.97)

保存・比較済みのオリジナルPNGを再生成せず使用し、弓術場II・IIIを拠点と建築カードへ接続しました。Iの緑の天幕・木製支柱・黄土色の縁取りを維持し、IIは追加の低い準備区画と三つの的、IIIは二つの高い天幕と四つの的で区別します。的の数は装飾であり、訓練や戦闘の効果を変えていません。

画像は各段階1回ずつ組込み画像生成で制作し、原bytesを永続保存・読戻し・SHA256・全デコード・PNG CRC・透過・目視確認済みです。出所とプロンプトは `ARTWORK-PROVENANCE.json` の `archeryRangeStagesII_III` に記録しています。I、住宅、炊事場、錬金工房、仕事場の完成済み画像は変更していません。

カードと拠点は共通の段階選択関数を使います。新PNGが失敗した場合はIへ、Iも失敗した場合は的・天幕・段階印の軽量SVGへ切り替えます。失敗は段階ごとに独立し、更新ごとの再試行はありません。拠点表示の上限はII48×44px、III52×48px、原画像の比率を維持します。代替SVGは画像障害用で、新アートの制作完了数へ含めません。

建築カードは実際の「訓練」カテゴリで確認。PC/390/320、通常／動きを減らす設定、各段階の本体差分、独立した画像欠損、有償I→II/II→IIIと保存再読込、実際の最大段階で全17施設を配置した画面、スクロール・予約編集・倍率・フォーカス等の回帰を、隔離Chromeと合成データで確認します。実機スマホ・人間の長時間評価とは区別します。

施設費用・時間・効果、ゲーム難度・戦闘・経済・報酬・保存形式は変更していません。残る専門施設の段階別画像は魔術研究所II・IIIです。開拓13地域の専用景観、非鉄系防具などの差分は別の未完範囲です。
