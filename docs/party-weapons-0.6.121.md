# ミスリルの弓・火杖の材質表示 — 0.6.121

既存の mithril_bow（ミスリルの弓）・mithril_staff（ミスリルの火杖）を、同じ仲間の人物・姿勢・縮尺を保った淡い青銀色の武器表示へ更新。管理と戦闘で実装備ID・仲間IDを照合し、銀白色・鋼の青灰色・オリハルコンの銅金色を維持します。主人公・他の仲間・数値・攻撃/詠唱/MP・経済・保存形式は変更しません。

公式image_genで元の仲間画像を武器部分のみ編集し、各1枚の生成PNGを永続保存・読戻し・SHA256・CRC・RGBA・透明な四隅で確認。弓は既存の保存済み候補を再利用し重複生成していません。元絵/銀/ミスリルの実寸比較で人物・衣装・姿勢・余白を確認し、弓の不透明領域の高さ差は0.17%、杖は0.33%、足元はそれぞれ0px/+2px。参照画像SHAと完全な編集指示をARTWORK-PROVENANCE.jsonへ追記し、既存7記録を保っています。

必要な装備画像だけを読み込み、欠損時は同じ仲間の元絵、さらに従来の代替表示へ移行。失敗URLの再要求・毎更新の画像属性変更・遅延読込で古い材質に戻る競合を確認。PC/390px/320px・通常/動きを減らす設定、管理/戦闘・連続装備切替・保存再読込・実詠唱と弓攻撃・主人公の混成防具を隔離合成セーブで検証。実セーブ・実機スマホ・人による長期プレイとは区別します。

0.6.119の自動製作切替スクロールと未編集訓練目標の現在Lv＋1追従を維持。作業/訓練の専用アニメーションは装備連動へ変更していません。

仲間の武器個別画像は全14種中10種。共有表示が残るのは鉄/ダイヤモンドの弓、火種/ダイヤモンドの杖の4種。主人公の剣/石の槍の材質差、作業訓練の装備連動、地域II/III、実機スマホ・人の長期評価は別の残りです。
