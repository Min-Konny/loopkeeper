# 住宅画像の読込復帰（0.6.82）

住宅PNGを1枚読めないだけで生成風景全体が旧描画へ戻る問題を修正。住宅I〜Vの元画像が正常なら描画は変更しない。失敗時だけ、既存の住宅SVGを再利用して背景・他施設・作業者を維持する。施設カードも同じ失敗を記憶し、壊れた画像や再試行ループを防ぐ。キャッシュはページ内だけで、セーブへ保存しない。

人口・建設費・時間・報酬・行商人・ゲームロジックは不変。新しい増築絵は含まない。専門施設画像や地域画像の追加も今回の範囲外。

検証：現行repoで利用できる52テスト、PC/390/320の正常時30条件と住宅画像欠損1条件、施設カード欠損3条件。正常時の住宅領域画素は全30条件で変更前と一致。過去の開発元606件を再実行したとは扱わない。実セーブを使わない隔離データのみ。実機スマホ・長時間復帰は未検証。
