# 自動製作のスクロールと訓練目標 — 0.6.119

自動製作の異種レシピ切替で、工房一覧の再描画が食事欄を一時的に取り外し、縮んだ高さにスクロール位置が丸められていました。食事欄が戻った後まで、作業一覧と野営地欄の位置を同じ同期描画トランザクションで保持します。毎フレーム過去の位置へ固定したり、手動スクロール・フォーカス操作を禁止したりする変更ではありません。実際の最終コンテンツ範囲への丸めは残ります。

予約に追加する訓練の未編集目標は、その時点の進行Lv＋1（最大100）です。一度選択した時の値を保持し続ける問題を修正。直接入力した値・入力途中の空欄・確定済み予約の目標は自動変更しません。未確定の入力下書きは従来どおり再読込では保存せず、確定済み予約は保存します。進行Lvは今世代の訓練進行で、襲撃Waveではありません。

隔離した合成セーブで、PC1280px・390px・320px、短いPC画面、通常/拡大作業一覧、途中/末尾、実製作・依存素材製作・自動補充の切替、手動ホイール、食事選択、折畳み、タブ移動、入力フォーカス、予約回数編集と一時停止、保存再読込を確認。訓練は通常/簡易表示の追従・明示入力・未完入力・予約保持と、5訓練系統・通常クリア/エンドレス/転生・上限100の境界を確認します。実機スマホやユーザー実セーブの検証ではありません。

ゲーム数値・難度・報酬・経済・食事効果・保存形式・画像資産は変更しません。保管中の銀装備アートはこの更新には含めません。
