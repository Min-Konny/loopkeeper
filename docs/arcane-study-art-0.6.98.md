# 魔術研究所II・III (0.6.98)

魔術研究所Iの元画像を維持し、IIに塔へ接続した二階建て書庫、IIIに二つの青い円錐屋根を持つ専用画像を追加しました。石造り・木組み・蔦・暖かい窓・天球儀・書物を既存画風へ合わせ、原画像の縦横比を維持します。右端の見切れを避け、II/IIIの中心をx453へ2pxだけ寄せ、上限をII47×50px、III49×60pxとしています。

組込み画像生成を各段階1回使用。原PNGを永続保存・読戻しし、SHA256、全デコード、PNG CRC、透過、目視を確認後、原bytesを製品へコピーしました。出所、プロンプト、bytes、寸法、SHA256は `ARTWORK-PROVENANCE.json` の `arcaneStudyStagesII_III` に保存しています。既存Iおよび先に更新した施設画像は不変です。

拠点と「訓練」カテゴリの建築カードは同じ段階選択を使います。新PNGが失敗した場合はIへ、Iも失敗した場合は塔・書物・段階印の軽量SVGへ切り替えます。失敗は段階ごとに独立し、描画更新のたびの再試行はありません。代替図を専用アートの完成数へ含めていません。

PC/390/320、通常／動きを減らす設定、3段階の本体差分、画像欠損4条件、有償I→II/II→IIIと保存再読込、全17施設を実際の最大段階にした画面、スクロール・予約編集・倍率・フォーカス等の回帰を、合成データと隔離Chromeで確認します。特に右端と仕事場への自然な前後関係を確認します。実機スマホ・人間の長時間評価とは区別します。

これで専門施設5種類のI〜III、計15枚が別のPNGへ対応します。ゲームの費用・効果・時間・戦闘・経済・難度・報酬・保存形式は変更していません。全グラフィック完成とは扱わず、実装から照合した未対応範囲・先読み容量・次の優先候補を [対応表](art-coverage-0.6.98.md) に整理しています。
