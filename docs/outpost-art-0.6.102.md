# 開拓地域の景観対応 — 0.6.102

湖畔は舟と広い桟橋の穏やかな水面、渓流は岩場・橋・流水・網の杭で描き分けました。保存済み湖畔画像を再生成せず再利用。先行した採掘拠点・薬草園・森は維持します。各地域のI/II/IIIは同じ基本景観を使い、専用のII/III差分が揃ったとは扱いません。

正規の組み込みimage_genによる独自PNG。元bytesを永続保存・読戻し・CRC・RGBA・寸法・SHA256・目視で確認し、加工せず配信。プロンプトと出所はARTWORK-PROVENANCE.jsonに追記しました。湖畔の1隅にはalpha1/255の微小な残りがあり、全隅alpha0とは表記しません。

画像対応表の2項目追加だけで、遅延読込・固定表示枠・画像失敗時の共通絵→軽量代替・失敗URL再要求防止を維持します。全13地域を一括先読みしません。収入・人口・効果・守護敵・条件・通常36波・セーブは不変です。利用可能171単体テスト、合成状態のPC1280/390/320・通常/低モーション・未解放/未建設/守護敵あり/稼働済み・切替/保存再読込・欠損・画像到着遅延・既存操作回帰で確認します。実機スマホや自然な全キャンペーンの攻略を実証した試験ではありません。

次は街道の仕事場/砦の交易拠点など用途の異なる未対応地域を小分けに進めます。地域ごとのII/III差分を先に大量追加しません。

共通画像失敗時は、まだ画面に出ていない同じ画像のカードも直ちに代替先へ揃えます。後で表示された未読込カードが、既知の失敗URLを再要求することを防ぎます。正常な専用画像は再読込しません。
