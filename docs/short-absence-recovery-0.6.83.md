# 0.6.83 短い離席進行の終了時保存

鶏舎の既存「短い離席の進行」ON・実行中でタブを通常終了しても、先行するpagehide処理が停止状態を保存し、離席再現が無効になっていた。二重の終了処理を統合し、既存session.onReleaseの保存順序を使う。OFF・手動停止時は停止状態を保存する。

新しいオフライン収益は追加しない。既存の明示ON・鶏舎建設済み・実行中の条件、最大60秒の通常ゲーム全体計算、死亡/選択/作業停止境界、読込後の一時停止を維持。材料費・戦闘・速度・保存形式・画像資産は変更しない。

検証は隔離した合成データのみ。通常終了→仮想6時間後再開の修正前は0秒、修正後は60秒・卵6、以後停止。保存失敗時の原本維持と再試行の一度だけ適用、支払い済み作業の再読込、襲撃境界、既定OFFを単体/エンジン比較で確認。利用可能な全57テスト成功。

PCブラウザ1280/390/320幅で仮想6時間・保存失敗復旧・再読込を確認。390/320は実機スマホではない。仮想時計のみを使用し、実時計やユーザーの保存領域は変更しない。ヘッドレスの別タブ切替ではdocument.hiddenにならなかったため、非表示タイマー方針はbackground-clock単体で確認した。実OSスリープ、実機スマホ、数時間の実時間放置、すべての多重タブ競合は未検証。

住宅II〜Vの新規絵は生成未完了のまま。バランス比較・Wave14検証・装備監査は別の有限検証であり、すべての残課題が解消したとは扱わない。
