# 鋼の弓・火杖の材質表示 — 0.6.118

実在する `steel_bow`（鋼の弓）と `steel_staff`（鋼の火杖）を、同一の弓使い/魔法使い・姿勢・縮尺で青灰色の鋼材に描き分けます。管理画面と戦闘の実装備に連動し、銅金色のオリハルコンと区別。材質・装備ID・仲間IDを明示的に照合します。主人公、ほかの仲間装備、性能・射撃/詠唱間隔・MP・経済・保存形式、作業/訓練専用アニメは不変です。

正規image_genで各1枚を元の仲間画像から非破壊編集し、受信したPNG全体を永続保存。PNGの再読込・CRC・RGBA・透明角・SHA256と、不透明範囲/実寸96×132管理・100×112戦闘/拡大比較を確認。人物や衣装を別物にせず武器材質だけを変更。完全な編集指示・参照画像SHAはARTWORK-PROVENANCE.jsonのpartyWeaponMaterialVariantsに記録。既存画像と記録は維持しています。

必要な装備のみ画像を読み、鋼画像が失敗したら同じ仲間の元画像→代替表示。上位材質や別の仲間へ誤代替せず、同じ失敗URLの反復と安定状態の不要なimg属性更新を抑えます。

材質別の個別画像は鉄クロスボウ・オリハルコン弩/弓/火杖・鋼弓/火杖の6装備。仲間14武器中ほかの8装備は共有ベースのまま、主人公の6剣/石の槍の材質専用絵、作業/訓練の装備連動、地域II/III専用差分、実機スマホ・人の長期評価は未完です。合成UI試験を実プレイ到達や実機確認とは扱いません。
