# 初達成クエスト（0.6.87）

契約とは別の、継承ポイントを獲得する初達成目標です。報酬は自動反映され、セーブ全体で一度だけ。転生・振り直し・同じ装備の再製作で再取得しません。

追加目標は通常12波、専門施設のいずれかをIIへ増築、異なる開拓3地域、通常24波、異なる開拓8地域。各1ptです。開拓は工事の完了だけでなく守護者の撃破履歴で判定します。旧ルートの攻防HPバフは追加しません。

オリハルコン装備の初製作は、既存の1件を合計10ptへ変更。武器・防具など部位ごとに10ptは得られません。旧セーブで同じ目標の1ptを受取済みなら、差額9ptを一度だけ補填します。現存する最上位装備でも未記録の初達成を確認できます。新しい目標の波と開拓は永続の突破履歴から判定し、施設は現在の実在施設から確認します。保存されていない過去の建築内容は推測しません。追加目標を一度達成した記録は、施設が転生で消えても保持します。

旧セーブの配分途中でも、継承ポイント残高と配分案の残高を同額増やし、既存の購入・返却権利を維持します。現在の保存上限を越える差額補填は保留し、保存を壊したり受取済みに変えたりしません。

全20件の総報酬は29pt。従来15件・15ptから、生涯最大14ptの増加です。序盤の既存報酬、敵、素材費、戦闘倍率、契約は変更していません。クリア世代数の設計目標は未設定で、固定方針の自動試験例は目標や人間の体感を保証する値ではありません。
