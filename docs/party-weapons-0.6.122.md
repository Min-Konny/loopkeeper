# ダイヤモンドの弓・火杖の表示 — 0.6.122

現行ゲームの武器名は「ダイヤモンドの弓」「ダイヤモンドの火杖」です。剣の「水晶刃」とは別の表示名です。装備ID・仲間IDを照合して、元の人物・姿勢・縮尺を保った白い結晶面と淡い青紫の武器画像へ切り替えます。銀白色やミスリルの淡い青銀色の画像も維持します。

公式image_genによる元の仲間画像の武器部分のみの編集で、各1回生成した保存済みPNGを再利用。新たな重複生成はしていません。永続保存・読戻し・SHA256・CRC・RGBA・透明な四隅を確認。元絵/ミスリル/ダイヤモンドの実寸比較で人物・衣装・姿勢・余白を確認し、不透明領域の高さ差は弓0.17%、杖0.58%、足元は+1px/+2px。完全な編集指示・参照画像SHAをARTWORK-PROVENANCE.jsonへ追記し、既存9記録を保っています。

必要な画像だけを読み込み、欠損時は同じ仲間の元絵、さらに従来の代替表示へ移行。失敗URLの再要求や遅延切替の競合を確認。PC/390px/320px、通常/動きを減らす設定、管理/戦闘・連続装備切替・保存再読込・実詠唱/弓攻撃・主人公の混成防具を隔離合成セーブで検証。実セーブ・実機スマホ・人による長期評価とは区別します。画像decodeと描画完了を待って画面比較しています。

性能・攻撃/詠唱/MP・経済・製作費・難度・保存形式は不変。0.6.119の自動製作スクロールと未編集訓練目標の現在Lv＋1追従を維持。作業/訓練の専用アニメーションは装備連動へ変更していません。
