# 主人公の木装備・混成表示 — 0.6.107

木の鎧の6武器系統と、独立した木・鉄の盾を組み合わせます。既存の鉄の鎧だけ・鉄の盾だけ・鉄鎧＋鉄盾の専用セットは変更していません。

|---|---|

|木盾のみ|共通主人公＋木盾|
|木鎧＋木盾|木鎧＋木盾|
|鉄鎧＋木盾|既存鉄鎧＋木盾|

武器6系統は剣・槍・弓・弩・杖・素手。両手武器では盾を背面へ、片手系統では前面へ配置し、鎧と盾の条件を独立して選びます。装備していない素材の全身セットへ勝手に置換しません。適用先は既存battle-uiの戦闘ダイアログ（Phaserと低モーションの静止肖像）。野営地の働き手、採集・工房・料理・訓練は別の作業アトラスで、今回の衣装変更対象ではありません。

新規画像は元の主人公・鉄盾を参照した組込みimage_genの独自画像2枚。原PNGをそのまま保存し、透明度・CRC・RGBA・寸法・SHA256を確認。生成履歴はARTWORK-PROVENANCE.jsonのheroWoodLayersに記録しています。槍の先が等分セルを越えるため、実測した個別範囲で切り出し、隣の弓の足を混入しません。木鎧と盾の画像は必要な装備のときだけ読み込み、失敗したファイルを同一ページで反復要求しません。合成は装備/武器系統ごとにキャッシュし、装備変更中の遅い応答で古い組合せへ戻しません。

検証は実セーブを使わない合成状態。PC1280/390/320、通常/低モーション、実ゲームの所持装備ボタン・混成切替・保存再読込、戦闘中の攻撃/被弾、欠損/遅延/不要読込/反復更新、54組の描画比較を確認。実ゲームの基本装備に外すボタンはないため、未装備状態は検証に通る別の初期状態で確認しました。表示確認の合成キャラは戦闘中に倒れない高い訓練防御を使い、攻略・到達率を実証するものではありません。実機スマホ、人による長期プレイは未検証。装備効果・数値・保存・ゲーム難度は不変です。

残る専用アートは革、鋼、銀、ミスリル、水晶、オリハルコンと、その盾・混成差分。開拓13地域の基本景観は完了ですが、地域別II/IIIは同じ地域基本絵で、全グラフィックの完了を意味しません。次は鋼の鎧・盾を、同じ独立レイヤー方式と実在装備条件に沿って進めます。
