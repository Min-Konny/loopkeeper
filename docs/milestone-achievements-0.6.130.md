# 旅の節目の実績 — 0.6.130

クリア時だけでなく、周回途中の意味のある進展も収集記録にします。既存の通常36波・少世代・3タイプ・2縛りの7実績は条件を維持し、以下の10個を加えて全17個です。継承ポイントや能力の追加報酬はありません。既存の初達成目標22個・64ptの処理も変更していません。

|鉄を手に|鉄等級以上の武器・防具・道具を入手|milestone_iron_equipment|
|鋼の備え|鋼等級以上の装備を入手|milestone_steel_equipment|

武器は主人公・護衛団とも対象です。上位等級で下位の節目も達成でき、全素材を順番に作る作業は要求しません。予約や支払い時点では入手・完成とは扱わず、実際の完了後に一度だけ記録します。同じ地域の再戦や同じアクセサリーの再製作で種類数は増えません。通常施設IIと専門施設IIは区別します。

旧セーブは現在の正当な所持品、永久解放、初達成目標の保存済み完了履歴から証明できるものを記録します。装備が失われていても対応する完了履歴があれば対象です。到達波・所持ポイントだけで装備入手を推測せず、証拠がなければ次の正当な達成を待ちます。旧履歴から復元した実績の世代は今回記録した世代で、過去の解除日時を作りません。クリア・タイプ・縛りは引き続き従来の履歴条件を使います。

既存の未受取の初達成報酬や旧バージョンの差額補填が別に発生することはありますが、その処理と今回の無報酬の実績は別です。例えば鉄の剣の製作は従来の初達成1ptだけで、新しい実績を理由に追加のポイントは付けません。

解除済みコレクションは転生・新しい挑戦・再読込・取込で保持します。新しい挑戦の確認と取消は既存のものを維持し、保存失敗時に現在の記録を置き換えません。実績IDは固定し、プラットフォームに依存しない解除イベントの境界を使います。今回Steamの設定・API・公開は行わず、将来の連携を保証するものではありません。

表示は「旅の節目10個」と「クリアへの挑戦7個」に分け、条件と記録状況を見られます。タイトルの長い一覧の末尾にも閉じるボタンを置きます。文言は定義と判定を分離していますが、全ゲームの翻訳と言語選択は将来要件です。

合成セーブによる単体・実ブラウザー検証を使用します。新規・旧達成済み・履歴不明・所持品による復元、実際の鉄製作、重複、転生、新しい挑戦、再読込、取込、保存失敗、PC/390/320幅と既存の操作回帰を確認します。実ユーザーのセーブや物理スマホは使用しません。
