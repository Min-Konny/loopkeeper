# 銀の弓・銀の火杖の材質表示 — 0.6.120

既存の silver_bow（銀の弓）・silver_staff（銀の火杖）を、同じ仲間の人物・姿勢・縮尺を保った銀白色の武器表示へ更新。管理と戦闘で実装備ID・仲間IDを照合し、既存の鋼の青灰色・オリハルコンの銅金色を維持します。主人公・他の仲間・数値・攻撃/詠唱/MP・経済・保存形式は変更しません。

公式image_genで元の仲間画像を精密編集した保存済みPNGを再利用し、新しい重複生成はしていません。全PNGの永続保存・読戻し・SHA256・CRC・RGBA・透明な四隅、元絵/鋼/銀の実サイズ比較を確認。人物の高さ差は弓0.08%、杖0.50%で足元・余白も維持。参照画像SHAと完全な編集指示をARTWORK-PROVENANCE.jsonへ追記し、既存記録を保っています。

必要な装備画像だけを読み込み、欠損時は同じ仲間の元絵、さらに従来の代替表示へ移行します。失敗URLの再要求・毎更新の画像属性変更・遅延読込で古い材質に戻る競合を確認。PC/390px/320px・通常/動きを減らす設定、管理/戦闘・連続装備切替・保存再読込・実詠唱と弓攻撃・主人公の混成防具を隔離合成セーブで検証。実セーブ・実機スマホ・人による長期プレイの検証とは区別します。

0.6.119の自動製作切替スクロールと未編集訓練目標の現在Lv＋1追従を維持。作業/訓練の専用アニメーションは装備連動へ変更していません。

仲間の武器個別画像は全14種中8種。未対応の共有表示は鉄/ミスリル/ダイヤモンドの弓、火種/ミスリル/ダイヤモンドの杖の6種です。主人公の剣/石の槍の材質差、作業訓練の装備連動、地域II/III、実機スマホ・人の長期評価は別の残りです。
