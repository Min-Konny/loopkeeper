# 通常36波の一区切り（0.6.91）

通常クリアは36波のまま。敵、報酬、資源、作業時間、エンドレスの仕様は変更しない。既存の最終ボス専用絵・戦闘の踏み込みや被弾表示・低モーション対応を維持し、新しいフラッシュ、画面揺れ、操作を待たせる演出は追加しない。

## 確認できた不足と対応

- 36波を勝っても死亡画面の紋章・文言・「次の命」が中心だった。通常36波を守り抜いた結果として見せ、初クリアと再クリアの見出しを分ける。
- エンドレス・通常の継承・第1世代からの再挑戦が離れていた。結果の先頭で3つを比較し、それぞれ何を保持／建て直すか説明する。新しい挑戦は既存の確認チェックと保存保護を経由し、取消できる。
- 拠点の襲撃予報がクリア後も残っていた。「通常36波クリア・次は任意」に変え、停止ボタンの位置に「クリア結果を見る」を置く。
- 永続ポイント・XPは既に集計されていたが、今回解放したアクセサリーや地域はまとまっていなかった。世代開始時の所持から差分を表示し、実際に今回解除したリプレイ実績も併記する。旧保存に基準がないものは推測せず、記録不足と示す。
- 受取済み初達成を次の目標として示さない。結果と既存のクエスト画面で、この挑戦の未達成目標を最大2件表示。即時制作可能という案内ではなく、既存条件を確認するための目標一覧とする。

戦闘・世代比較・継承技能の詳しい記録と共有画像の操作は折りたたみに保持。クリア結果は明示的に閉じられ、同じ結果を閉じた後の再読込では強制再表示しない。拠点の結果ボタンからいつでも開ける。勝利直後に閉じず再読込した場合は再度結果を表示するが、報酬・実績は再付与しない。この表示設定はブラウザのUI用キー1件で、ゲームの進行や停止状態を変更しない。設定保存不可でも進行を止めない。

## 観測用保存情報

任意の `run.results.startAccessories` / `startRouteClears` に世代開始時の永久所持を記録。`run.clearAchievements` は実際の解除イベントのIDだけを保持。既存保存のこれらの欠損は許容し、値がある場合は定義IDと重複を検証する。通常クリアの結果値・経済・戦闘ルールは変えない。

## 検証の範囲

実セーブを使わない固定攻略で第14世代の初クリア、その保存を通常の継承・支出・制作で続けて第15世代の再クリアを確認。0.6.90の同条件・同じ抽選seedと、全世代の行動列・資源・報酬・戦闘・所要時間が一致。最終保存も追加した観測用情報と挑戦IDを除いて一致。

隔離ブラウザの1280/390/320幅で、戦闘途中再読込、勝利直後再読込、結果を閉じて再読込、キーボードで結果を再表示、新挑戦取消と明示開始、エンドレス移行後の資産保持、再クリア表示を確認。通常・低モーション、自動作業中のスクロール、予約回数編集と停止状態、再読込の回帰も対象。

実機スマホ、長期的な人間の達成感、Steam設定・配布・認証の検証は含まない。地域や施設の追加アート、住宅III〜V、50波目標の案は別件のまま。装飾や波数を増やして全体完成と扱わない。
