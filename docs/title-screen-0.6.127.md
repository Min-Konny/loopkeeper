# タイトル画面 — 0.6.127

既存の森林・野営地PNGとマークを再利用した入口です。初回は「はじめから」、保存があれば「つづきから」が主導線になります。設定とリプレイ実績はゲームを開始せずに確認できます。既存データはタイトル表示だけでは保存も初期化もしません。ゲーム本体の読み込みは明示的な選択後で、タイトルでは将来段階の施設や戦闘画像を先読みしません。画像失敗時も背景色と操作を残し、本体の低速読み込み中は読み込み表示、失敗時は再読み込みの案内を残します。

## 保存と時間

- タイトルではゲームループ・音声・Phaser・オンライン進行を起動しません。続行時だけ従来の所有権取得・移行・オフライン処理を使います。既存の「農場オフライン」設定と最大60秒のエンジン再生は変更しません。初回起動前に保存されていた稼働中の記録では、タイトルの待機時間も既存仕様上の離席時間になります。別時計や二重精算は作りません。
- 続行は既存仕様と同じ一時停止で開きます。ゲームの設定とメニューにある「保存してタイトルへ」は一時停止・チェックポイント保存が成功した場合だけ同じページを再読込し、本体が裏で動かない状態へ戻ります。保存失敗や操作権なしでは戻らず、既存の進行と予約を保持します。
- 新規開始は既存の新しい挑戦処理を使用。保存がある場合は失われる進行と残る解除済みリプレイ実績を明示し、確認チェックと取消を用意します。直前の挑戦は従来の保存メニューから復元できます。壊れた記録は明示的な新規開始時に従来の読み取り不能アーカイブへ保管します。読み取れない実績は推測で授与しません。
- タイトルから書く操作も本体と同じWeb Locksのwriterを使用し、プレイ中の別タブを上書きしません。設定は許可した音量・演出・非表示時停止の項目だけを編集し、保存時刻・生の一時停止状態・支払い済み作業・予約・オフライン設定を保持します。タイトル設定だけで新規セーブを作ることはありません。保存状態が別タブで変化した場合は編集を拒否します。

## 多言語化の下地

`title-copy.js`は安定した文言キーと名前付き変数を使います。UI言語は進行セーブと別のキーを使う境界を用意し、未知の言語は日本語に戻します。現在の完成辞書は日本語だけで、未翻訳の選択肢は公開しません。全ゲームの文言移行・翻訳・設定での言語選択は今後の作業であり、今回の更新で完了したとは扱いません。進行IDや数値を翻訳文字列へ置き換えていません。
