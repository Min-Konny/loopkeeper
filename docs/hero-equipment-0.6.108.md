# 鋼の鎧・盾 — 0.6.108

鋼の鎧の6武器姿勢と、前面/背面の2向きの鋼盾を追加。木・鉄・鋼の鎧と盾は装備スロットから独立して選びます。鋼＋木、鋼＋鉄、木＋鋼、鉄＋鋼、鋼＋鋼、鎧なし＋鋼盾を表現します。既存の鉄鎧/鉄盾セットと木装備は維持します。鋼盾は広い上縁と尖った下端を持つ形で、丸い鉄盾とは別の輪郭です。

銀・ミスリル・水晶・オリハルコン・革の鎧は専用絵が未制作。これらの鎧＋対応済み盾では共通主人公と盾を表示し、その鎧の素材を正確に描けたとは扱いません。木/鉄/鋼鎧＋未対応素材の盾では鎧を表現し、盾の専用絵は未制作です。

適用先はbattle-uiが表示する戦闘ダイアログのPhaserと静止肖像。野営地の働き手や採集・工房・料理・訓練は従来の専用アニメで、今回の装備別衣装反映はしていません。装備の性能・所持判定・費用・数値・セーブは変更しません。

画像は正規の組込みimage_genによる独自素材。保存済み候補を再生成せず使用し、PNG原bytes・CRC・RGBA・透明度・寸法・SHA256を確認。heroSteelLayersの由来記録に生成指示と参照元を残しています。実際のコマ境界を測定し、槍先や隣の弓の足を切らずに切り出します。前後2向きの鋼盾は2列1行で、旧盾の2列2行とは独立して読み込みます。

素材ごとに必要時だけロードし、既知の失敗ファイルを同じページで繰り返し要求しません。混成の合成結果を体/武器/盾ごとにキャッシュし、遅い旧装備の応答が現在装備を上書きしない構造を維持。旧木/鉄48組は0.6.107の実装と生成テクスチャを比較します。

合成セーブでPC1280/390/320、通常/低モーション、演出OFF、実UI装備切替と保存再読込、戦闘中の攻撃/被弾、欠損・遅延・反復更新、96組の描画比較を確認。表示確認の防御は合成状態用に高く設定し、攻略や到達率の実証には使いません。実ユーザーセーブ、実機スマホ、人による長時間プレイは対象外です。利用可能な単体テスト、構文/import/保存ロジック不変の監査、Pages CIと配信・公開操作を確認します。

次は銀の鎧・盾、その後ミスリル等を段階的に追加。開拓13地域の基本景観は完了していますが、地域別II/IIIや全装備のアートが完成したという意味ではありません。
