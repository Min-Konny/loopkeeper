# 管理画面UI（0.6.89）

PCは作業と予約の左右配置を維持し、レール幅を抑え通常行動カードを読みやすい幅へ。1280pxの確認条件では作業幅685→724px。1/2/5倍を直接ボタン化し、選択状態とキーボードフォーカスを表示します。

スマホは7つの主要タブをラベル付きの下部ナビへ。4タブ＋その他の比較案は採用せず、継承・交易などを追加クリックの奥に移しません。技能一覧はメニューへ移動し、PCへ広げるとサイドバーへ戻ります。行動カード内の進行/永続レベル表示は維持。作業幅は390pxで322→378px、320pxで252→308px。

通常のスマホ画面は二重縦スクロールをやめ、画面全体の1本へ。HP・襲撃時間・速度・停止操作は上部に固定します。資源は名前付きの横トレイで数値を省略せず表示し、横位置とフォーカスを自動更新でも維持。予約欄は増設せず、スマホだけ先頭・残り回数と編集入口を作業の近くへ表示します。予約ダイアログを開く間の一時停止は従来仕様で、閉じると元の状態へ戻ります。

風景はスマホでは初期状態で折りたたみ、開閉はスマホ用キーに保持します。PCの既存の風景設定は維持。明示的な拡大表示は残し、タブ移動だけではスマホに全画面ダイアログを開きません。

入力・ネイティブセレクター・主ボタン・閉じるボタンの寸法、角丸、枠、フォーカス、選択/無効状態を共通化。低モーションを尊重します。ゲームエンジン、時間倍率の計算、難度、報酬、セーブ形式、実績は変更しません。既存セーブの通常データとUIの表示設定は別です。

PCブラウザの1280/390/320幅・短い高さ700pxで検証。実機iOS/Androidのキーボード・セーフエリア・支援技術の全組合せは未検証です。
