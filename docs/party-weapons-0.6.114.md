# 仲間の弓／弩の持ち替え — 0.6.114

弓使いの管理画面・戦闘画面を、実際の仲間装備のcombat.typeから選ぶ表示専用の境界へ変更。弓は従来の原画、弩は同じ人物・服・縮尺の専用原画を使用。未選択は従来UIの「初期装備」と基礎攻撃を維持し、素手化や新しい装備解除操作は追加しません。魔法使いと主人公の装備先も変更しません。

原画は組込みimage_genで自作party-archer-v1.pngを編集した1枚。顔・衣装・足元・照明を維持して両手で弩を構え、長い弓と矢の残像を除去。1254×1254、RGBA、透過四隅0/0/1/0、PNG CRC・実bytes・SHA256・通常HTMLでの再読込と目視を確認。ARTWORK-PROVENANCE.jsonのpartyWeaponVariantsに指示文・参照原画・ハッシュを保存し、受信PNGのbytesは変更していません。

固定サイズのimg属性のみ更新し、不要なDOMの作り直しや新たなタイマーを加えません。弩画像が失敗すれば従来の弓使い、そちらも失敗すれば軽量な代替記号へ切替。画像代替の状態を保持し、同じ失敗URLを再要求しません。遅延した旧リクエストで現在の選択へ戻さず、未加入の画像を失敗処理で読み始めないようにします。

合成セーブでPC1280/390/320、通常/低モーション、初期装備・弓・弩、連続切替、再読込、戦闘開始・射撃・終了を36観測。仲間の変更前後で主人公の装備・画像、資源・停止状態・経過時間を確認。戦闘終了は合成の通常第1波でのUI確認で、攻略や難度の実証ではありません。欠損/遅延4ケースでは1000更新、不要な画像属性変更や再要求、未加入先への不正URL要求を確認。206単体テスト、スクロール・予約編集・保存6回帰、構文/import・既存ゲーム処理不変監査を実施します。

攻撃力・発射間隔・報酬・経済・保存形式・実セーブは変更しません。作業/訓練は専用アニメを維持。武器の材質別差分、開拓地域II/III、実機スマホ・人の長期プレイは今回完了したものではありません。公開は当該CI・配信ファイル一致・公開版操作で確認します。
