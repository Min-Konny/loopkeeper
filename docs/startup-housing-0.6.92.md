# 起動時の案内と住宅III（0.6.92）

## 起動・通信失敗

以前の入口は空の `#app` と案内なしの動的importだけで、読み込み中や入口ファイルの失敗で空画面になった。HTML内に軽量な起動表示を置き、15秒経過時は時間がかかっていることを伝える。割合や残り秒数は推測しない。入口モジュールのimport失敗を捕捉し、明示的な「再読み込み」を表示する。自動リロード、保存の初期化、新しいオフライン報酬は追加しない。正常起動後は既存UIが起動表示を置き換える。

隔離したPCブラウザのローカルサーバーで、200ms遅延・393216bytes/s（約3Mbps）の条件を使用。基準測定では操作可能まで約10秒、その前は空画面だった。変更後も操作可能まで約10秒であり、今回の改善は速度向上ではなく待機状態と失敗後の復帰の明確化。再読込は同じ条件で約18秒。テストサーバーは静的Cache-Control付き・ETagなしのため、この時間を実公開や全回線の所要時間と扱わない。

PC/390/320幅で入口ファイルを失敗させ、元の保存文字列が不変で、再読み込み後も支払い済み材料と作業進捗を維持することを確認。画像8秒遅延／全PNG失敗中も行動カードの高さ、入力値・フォーカス、自動作業を確認。入口を18秒遅らせる試験で長時間表示も確認。設定は検証用ブラウザ内のみで、PCのネットワークやセキュリティは変更しない。

## 住宅IIIの画像

`assets/pixel-v2/housing-stage-3-v1.png` を正規の組み込みimagegenで1枚生成。1312×1199 RGBA PNG、2037476bytes、SHA256 `d2574c1ae37176b8f03af5068af92e0ceb4742c6066d0f9fc778597590dbfafe`。透明背景。原本バイトを保持し、由来・全プロンプトは同ディレクトリの `ARTWORK-PROVENANCE.json` の `housingStageIII` に記録。

生成前に画像相当2MiBの保存・読戻しを1回確認し、生成結果は受信後そのまま永続ファイルへ保存。PNGの展開、透明部、ファイル再読込、実画像を確認してから接続した。API/CLIへの切替や追加生成はしていない。

I/IIの元画像は不変。IIIだけ新しい二階建ての輪郭へ接続し、拠点内では56×49の枠に収める。IV/Vの専用絵は未制作で、従来の共通画像と段階マークを維持する。画像欠損時は既存の段階別SVG代替へ切り替え、他の段階へ失敗を波及させない。

PC/390/320、通常／低モーション、全I〜V、欠損、II→IIIの支払い済み建築完了を隔離データで確認。拠点では段階マークを含まない住宅本体領域の2250画素がIIからIIIで変化し、素材を置いただけでなく実際の描画更新を確認した。

## 維持した範囲と限界

通常36波、難度、報酬、資源、保存形式、既存UIのゲーム操作は変更しない。既存のスクロール・予約回数編集・停止状態の回帰も対象。物理スマホ、全種類の回線断やブラウザ拡張、長時間の人間のプレイ評価は含まない。住宅IV/V、地域・専門施設の追加段階素材は別件のまま。Steam公開・他プロジェクト変更は対象外。
