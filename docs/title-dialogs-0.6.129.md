# タイトル確認ボタン修正 — 0.6.129

タイトル画面の右上にある「×」ボタンの寸法指定が、同じ閉じる属性を持つ下部の「キャンセル」にも適用されていました。幅44px・文字24pxで文字が縦に折り返され、PCでは隣の実行ボタンもflexの高さに追従していました。PC/390px/320pxで再現し、キャンセルの高さは約214pxでした。設定のキャンセルにも同じ原因がありました。

アイコン用の指定をタイトルダイアログのヘッダー内に限定しました。右上は44px角、下部は通常の文字・余白で、PCは横並び、狭い幅は全幅の縦並びを維持します。文章やボタン文字は切り捨てず、ダイアログの内容が長い場合は通常どおりスクロールできます。固定の巨大な高さや文字を隠す処置はしていません。

合成セーブと隔離ブラウザーで、タイトルの新規確認/設定/実績、ゲーム内の新規確認/保存/次世代確認の6種類をPC/390/320の18条件で照合しました。影響はタイトル新規と設定の計6条件で再現し、他の確認画面はこの不具合を再現しませんでした。修正後は全18条件で文字ボタンの幅・高さ・はみ出し、取消による保存保持を確認します。短い画面・キーボード・長い文言と既存操作の回帰も確認します。

ゲーム数値・難度・報酬・実績条件・セーブ形式は不変です。節目実績追加と新しい採集小物はこの修正に混ぜていません。実セーブと物理スマホは使用しません。
