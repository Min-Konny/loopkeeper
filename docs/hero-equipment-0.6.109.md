# 銀の鎧・盾 — 0.6.109

銀の鎧の6武器ポーズと、銀盾の表・裏2方向を追加。鎧と盾は個別の描画スロットとして扱い、木・鉄・鋼との混成、鎧なし＋銀盾、銀鎧＋盾なしも表示します。銀の淡い板金と細い彫金、細長い盾の輪郭で鋼と区別します。既存の木・鉄・鋼90組は旧版と生成テクスチャが完全一致します。

適用範囲は battle-ui の戦闘ダイアログ、Phaser と静止表示です。野営地の働き手、採集・工房・料理・訓練は従来の専用アニメで、装備差分は反映しません。ミスリル・ダイヤ・オリハルコン・革は専用防具アート未対応。未対応鎧は新共通主人公、未対応盾は専用表示なしとなり、旧SVGに戻しません。13地域の基本景観は完了していますが地域II/IIIの専用差分は未完です。

独自画像は組込み image_gen で自作鋼装備を参照して生成し、保存済み原画を再生成せず使用。heroSilverLayers の由来記録にプロンプト・参照画像・ハッシュを保存。PNGの実bytes、CRC、RGBA、寸法とSHA256を検証し、実コマの境界を測定して槍先・弓の足を切らないよう切り出しています。盾は2列1行。画像は必要時だけ読み込み、失敗URLは同ページで再要求せず、遅延完了が現在の装備を上書きしません。

独立した合成セーブでPC1280/390/320、通常/低モーション、演出OFF、実UIの切替・再読込・混成、戦闘中の攻撃/被弾、欠損・遅延・連続更新を確認。150組の描画比較と旧90組の一致、191単体テスト、スクロール/予約編集/保存の6回帰、構文/import/計算・保存ロジック不変監査を実施します。描画用戦闘の防御は高く設定しており、進行・難度の実証には使いません。実ユーザーセーブ、実機スマホ、人の長時間プレイは未検証です。公開完了は当該commitのCI・実ファイル一致・公開操作確認で判断します。
