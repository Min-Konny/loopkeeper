# 開拓地域の景観対応 — 0.6.101

今回の更新は既存の峠の採掘拠点・湿地の薬草園の基本景観だけです。森は丸太/斧/木材小屋を備えた既存の良い画像を再利用します。新しい地域・資源・効果は追加しません。I/II/IIIはそれぞれ同じ地域の基本絵を使い、名称と段階表示は従来どおりです。段階別専用絵が完成したという意味ではありません。

|ID|地域|基本景観|
|---|---|---|
|forest|森の伐採拠点|既存の森向け画像を再利用|
|quarry|峠の採掘拠点|新規：石材・石切り場・トロッコ|
|marsh|湿地の薬草園|新規：薬草の植え床・乾燥棚・木道|
|lake|湖畔の漁場|共通画像のまま（未対応）|
|road|街道の仕事場|共通画像のまま（未対応）|
|forest_depth|深森の伐採拠点|共通画像のまま（未対応）|
|quarry_depth|峠奥地の鉱山|共通画像のまま（未対応）|
|marsh_depth|湿地奥地の薬草園|共通画像のまま（未対応）|
|citadel|砦の交易拠点|共通画像のまま（未対応）|
|river|渓流の漁場|共通画像のまま（未対応）|
|forge|工房街の製錬所|共通画像のまま（未対応）|
|observatory|星見の宝石採掘場|共通画像のまま（未対応）|
|ice|氷冠の鉱山|共通画像のまま（未対応）|

画像は正規の組み込みimage_genで作成。元PNGを永続保存し、読戻し・CRC・RGBA・寸法・SHA256・目視を確認して、そのbytesを加工せず配信します。出所/プロンプト/ハッシュはARTWORK-PROVENANCE.jsonに記録。各画像の1隅にalpha1/255の微小な残りがあり、全隅alpha0とは表記しません。

画像名の対応は表示専用モジュールに限定。未解放地域は従来どおり文字の目標一覧だけで画像を作りません。カードはloading=lazy/decoding=async、幅160×高さ120を予約し、全13地域の画像を一括先読みする処理はありません。失敗した新画像は森の共通絵、その共通絵も失敗した時は軽量な中立拠点へ切り替え、同じ失敗URLを繰り返し要求しません。

収入・人口・資源・守護敵・解放/建設条件・難度・セーブ形式は不変。検証には隔離した合成状態を用います。未開放、未建設、守護敵あり、稼働済みI/III、PC1280/390/320、通常/低モーション、タブ連続切替、画像失敗と保存再読込を確認しました。実機スマホや合法な全キャンペーン進行の実証は今回のUI試験には含みません。次は湖畔/渓流など別用途の小さなバッチを優先します。

利用可能168単体テストを通過。討伐済み合成状態は実際の守護戦処理で解除記録を生成して保存検証を通しました。素材・資金の獲得過程や通常攻略の難易度を実証した試験ではありません。画像失敗時は代替先の読込完了を待って検査し、途中のdecode取消を製品不具合とは扱いません。
