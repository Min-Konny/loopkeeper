# 準備周と攻略周（0.6.88）

強制モードは追加しません。最高Wave更新以外にも、未達成ポイント・ボス/作業素材・永久アクセサリーを残せる既存経路を案内します。装備セットは準備用/戦闘用で別に保存。アクセサリーと素材は永続、通常装備・施設は世代内です。

配点：最初の7目標は各1ptを維持。鋼2、施設II2、外交1、相乗効果2、通常12波2、専門施設II3、開拓3地域3、銀3、ミスリル5、通常24波5、開拓8地域6、ダイヤ7、オリハルコン10。新規にアクセサリー初解放2・3種類解放4。全22目標64pt、従来29ptから最大35pt増。

報酬は全世代を通じ一度。受取済みの各目標は、保存された旧改定版の額と現在額の正の差額だけ一度補填します。オリハルコンは0.6.87受取済みなら追加なし、それ以前の1ptなら9pt。未受取は現在額で一度だけ。配分中の台帳も同額増加し、上限超過時は補填済みにせず保留します。

継承ランクは1/2/3/4/5ptという費用。3ptは新規1系統のR2までの合計、既取得の下位ランクがあれば次の1段に集中することもできます。追加報酬は敵の所持ポイント連動には使いません。

難所：次の新しい世代から通常27/36波に士気高揚（4攻撃ごと+5%、最大+30%）、33波に破甲（4回ごと防御の効力60%）。既存30波の破甲と45秒後の長期戦成長は維持。HP・基本攻撃値・序盤・開拓守護者・エンドレスには追加倍率なし。旧セーブの現在の周・既に始まった敵には遡及せず、次の世代から適用。後半を火力・HP・回復・装備セットで準備する狙いです。

UI全体配置案は未公開で別検討。実セーブは検証に使いません。固定方針/乱数による到達は実プレイの保証や目標世代数ではありません。
