# 炊事場II・IIIの段階別アート (0.6.94)

炊事場Iの元画像は維持し、IIに追加の炉と低い別棟、IIIに双屋根と三つの炉を持つ専用画像を追加しました。既存の木組み、漆喰、苔のある瓦屋根、銅鍋、暖かい窓の光に合わせています。原画像を変形せず、比率を保って拠点・建築カードへ表示します。拠点の幅はII47px、III53pxに制限しています。

組込み画像生成を各段階1回ずつ使用。受信後にPNGを永続保存し、SHA256・bytes・全デコード・透過・読戻し・目視を確認しました。原bytesを製品へコピーし、プロンプトと出所は `ARTWORK-PROVENANCE.json` の `kitchenStagesII_III` に保存しています。第三者の画像、新しいライブラリ、別の生成APIは使用していません。

拠点とカードは同じ段階選択関数を使います。新画像が欠けた場合は元の炊事場Iへ、元画像も失敗した場合は段階印付きの軽量なSVG代替表示へ切り替えます。一つの段階の失敗で他の段階を抑止せず、更新ごとの画像再試行もしません。代替図は通信失敗用であり、新しい専用アートとして数えていません。

確認範囲：利用可能な全122単体テスト、189モジュールの構文・相対参照、起動script構文、既存202ソースの意味的な不変性、元の炊事場Iと住宅I〜Vのbytes一致。PC/390/320幅と通常・動きを減らす設定で、拠点・カード・横幅・段階の本体差分、独立した画像失敗、支払い済みI→II/II→IIIと保存再読込、実際の最大建築段階で全施設を並べた画面を合成データで確認します。実機スマートフォンや人間の長時間評価とは区別します。

通常36波、敵・報酬・継承・費用・時間・施設効果・保存形式は変更していません。他の専門施設4種類のII/III、地域別拠点、非鉄系防具の専用アートは引き続き未対応です。住宅の0.6.93更新とは別コミットとして保存します。
