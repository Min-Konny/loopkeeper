# 護衛団の訓練表示 — 0.6.128

弓の稽古と魔法の鍛錬は護衛団の訓練です。管理画面・戦闘では実装備の素材/種類画像を選んでいましたが、作業表示と行動カードは弓使い/魔法使いの初期画像に固定されていました。既存14武器のうち12武器で材質または弩の違いが見えないことを静的監査し、上位弩/杖の実画面でも確認済みでした。

今回、表示専用の引数で現在の状態を渡し、既存の護衛団画像選択・欠損フォールバックを再利用します。人物やポーズ、ピクセル画像、訓練のCSS寸法/動きは作り直しません。主人公の剣や防具を仲間の武器として判定しません。未装備では従来の基本画像を維持します。仲間武器を外す操作は現行UIにないため、新しい解除操作は追加していません。未装備は合法なテスト状態で確認します。

対象は鉄/鋼/銀/ミスリル/ダイヤモンド/オリハルコンの弓、鉄/オリハルコンの弩、火種/鋼/銀/ミスリル/ダイヤモンド/オリハルコンの杖の計14種です。表示名は現行の装備定義を使います。訓練アクションIDは `train_archery` と `train_magic` です。

新しい素材・別ポーズは制作せず、全画像と由来記録を維持。画像は必要な装備時に読み、失敗確定後は既存の失敗キャッシュを使います。遅れて到着した旧装備の画像で現在の装備を上書きしません。全ての作業/訓練アニメに主人公の全防具差分を実装したわけではありません。

合成セーブで、14武器の選択と保存値不変、主人公との分離、旧呼出し互換、他作業のマークアップ不変を単体検証。実ブラウザーではPC/390/320・通常/低モーションの12状態で84回の実装備変更、訓練作業表示/カード/再読込/タイトル往復、欠損・遅延・未装備・実際の予約完了による弓訓練→魔法訓練の切替を確認します。既存の村UI、製作切替スクロール、予約編集、訓練目標現在Lv+1、201件保存境界とタイトル保存安全性の回帰も維持します。実セーブと実機スマホは使いません。

訓練の時間・経験値・費用・戦闘計算・難度・報酬・セーブ形式は変更していません。
