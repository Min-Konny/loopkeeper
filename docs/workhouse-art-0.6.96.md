# 仕事場II・IIIの段階別アート (0.6.96)

保存・比較済みのオリジナル画像を使い、仕事場II・IIIを拠点と建築カードへ接続しました。Iの黄土色の屋根・木組み・蹄鉄の看板・修繕台の画風を維持し、IIは追加の屋根付き作業区画、IIIは二つの高い切妻と三つの作業台で区別します。元画像の比率を保ち、拠点の表示範囲はII48×45px、III52×49pxに制限します。

組込み画像生成を各段階1回使用して制作済みのPNGを再利用し、今回の組込みにあたって再生成はしていません。原bytesを永続保存し、SHA256・全デコード・PNG CRC・透過・読戻し・目視を確認済みです。制作方式、プロンプト、bytes、寸法、SHA256は `assets/pixel-v2/ARTWORK-PROVENANCE.json` の `workhouseStagesII_III` に記録しています。既存の仕事場I、住宅I〜V、炊事場I〜III、錬金工房I〜IIIの画像は変更していません。

拠点とカードは共通の段階選択関数を使います。新PNGが失敗した場合は仕事場Iへ、Iも失敗した場合は作業台・車輪・段階印の軽量SVGへ切り替えます。段階ごとの失敗は独立し、描画更新のたびに再試行しません。代替SVGは通信失敗用であり、新しい専用アートに数えていません。

利用可能な全単体テスト、JS構文・相対参照と起動script、ゲーム・保存処理の不変性、PC/390/320幅と通常／動きを減らす設定の拠点・カード、画像失敗、有償I→II/II→IIIと保存再読込、全17施設を実際の最大段階にした画面、スクロール・予約編集・倍率・フォーカス等の回帰を合成データで確認します。実ユーザーのセーブや実機スマートフォンは使っていません。

施設の費用・効果・建築時間、戦闘・経済・難度・報酬・保存形式は変更していません。残る専門施設のII/III専用画像は弓術場と魔術研究所の4種類です。地域別拠点13種類、非鉄系防具などは別の未完範囲です。
