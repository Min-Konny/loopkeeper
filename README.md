# LoopKeeper: Idle Defense 0.6.16

公開先: https://min-konny.github.io/loopkeeper/?v=0.6.16

- 前回最高まで戻り、新しい壁を25%以上削って進展せずに敗れた人生は、通常の挑戦報酬に+1pt。各人生1回で、早い地点への撤退や寄り道では得られません。
- 大鍋・保存食の本人調理を短縮し、鍛冶の育成効率を調整。材料と生産量、自動スープ、採集NPC、食料回復は維持します。
- 調整後の地域の敵を保存できず、出発操作が取り消される不具合を修正しました。
- 数値の調整は新規開始と次の転生確定から。現在人生の数値・継承・支払済み作業を保ち、地域の保存修正は現在人生でも反映します。

既存の保存・所持品・本編進行を保持します。保存データは端末のブラウザー内にあります。
