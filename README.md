# LoopKeeper: Idle Defense 0.6.4

公開先: https://min-konny.github.io/loopkeeper/?v=0.6.4

- 新規開始と次の転生から、W1–12の壁と突破後の進行、再挑戦の継承報酬を調整します。現在進行中の人生には適用しません。
- 魚・石炭・銀鉱石・鋼をまとめて作業します。所要時間・材料・経験値も同じ比率で増え、支払済み作業の内容を保持します。
- 敗北時に敵の残りHP、前回との比較、今回の継承報酬と成長の手掛かりを表示します。
- 保存・所持品・購入済み強化・継承ポイントを維持します。採集の初回受取は長くなります。

既存の保存・所持品・本編進行を保持します。保存データは端末のブラウザー内にあります。

## 適用時期と確認範囲

新規開始は新設定です。既存セーブの現在の人生・支払済み作業は維持し、次の転生の確定保存から新設定に切り替えます。転生準備を開いただけでは切り替えません。転生による通常作業のリセットは従来どおりです。比較試作のURLパラメーターは公開版の設定を変更しません。

序盤の繰り返しを伴う設計です。自動比較では従来より突破までの総時間が増える条件もあり、人の操作感の最終判断は残ります。W15以降の敵・継承価格・武器構成は変更していません。
