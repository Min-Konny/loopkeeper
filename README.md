# LoopKeeper: Idle Defense 0.6.6

公開先: https://min-konny.github.io/loopkeeper/?v=0.6.6

- PCの通常表示と拡大表示で、右側に予約列を表示します。作業一覧と予約順を同時に見て、回数変更・並べ替え・停止と再開ができます。
- 野営地の絵を小アイコンから全景表示へ戻します。PCでは右側に配置し、作業一覧の高さを保ちます。風景は大きく表示することもできます。
- 狭幅では予約ボタンから編集し、野営地の絵を横幅いっぱいに表示します。風景は折りたたみ可能です。設定・停止通知の修正を維持します。
- 戦闘・報酬・保存形式・解放条件は変更しません。セーブ削除や転生は不要です。

既存の保存・所持品・本編進行を保持します。保存データは端末のブラウザー内にあります。

右列の表示条件: 幅1000px以上で行動予約を解放済み（W2突破済み等）の場合、通常表示と拡大表示に表示します。幅1000px未満は予約ボタンを利用します。PCの野営地は右側に全景表示し、低い画面では予約を先に配置します。狭幅では風景を全幅表示し、折りたたみ状態を記憶します。風景は大きく表示できます。
