# LoopKeeper: Idle Defense 0.6.12

公開先: https://min-konny.github.io/loopkeeper/?v=0.6.12

- 継承ポイントの購入・振り直し・能力の構成変更を転生前の配分画面へ統一。生存中は取得済みの力と次の候補を確認できます。
- この命で獲得したポイントは保ち、確定した次の命から新しい配分が反映。既存の能力と購入時の実支払額は維持します。
- 配分の保存失敗・取消・再読込・操作権移動・二重確定を保護。旧形式セーブは既存の転生操作から配分画面へ移れます。
- WAVE1の無料予約解放と、自動調理・人員の通常のON/OFF操作を維持。敵・回復・材料・経験値・自動化の数値調整は別途検証します。

既存の保存・所持品・本編進行を保持します。保存データは端末のブラウザー内にあります。
