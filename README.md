# LoopKeeper: Idle Defense 0.6.9

公開先: https://min-konny.github.io/loopkeeper/?v=0.6.9

- 持ち物は「すべて」から開き、通常資源・魚・金属・装備・永久素材を同じ一覧で確認できます。メニューを移っても所持中の品を隠しません。
- 分類・件数・数量と安定した並び順を整理。所持0は明示切替にし、特殊素材・永久アクセサリー・相棒も区別します。
- 上部の資源は食料・金貨に固定し、狭幅の拡大作業画面からも直接持ち物を開けます。広いPC作業領域と右予約列・野営地・設定は維持します。
- 戦闘・報酬・所有品・セーブ形式は0.6.8のままです。再読込で反映し、セーブ削除や転生は不要です。

既存の保存・所持品・本編進行を保持します。保存データは端末のブラウザー内にあります。
