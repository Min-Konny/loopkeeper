# LoopKeeper: Idle Defense

MVPテスト版 0.2.15。採集・製作・村づくりで備え、自動戦闘の襲撃を迎え撃つ資源管理ゲームです。第21波の勝利が今回のクリア地点です。

死亡するとその周の資源や装備を失い、技能の永続経験・初達成の記録・継承ポイントは次の命へ残ります。まず資源・装備・食料を準備し、初達成のクエストで便利な機能を解放してください。何も作業していないとき、画面を離れたときは時間が止まります。

セーブはこのブラウザーに保存します。右上の保存メニューでファイルへ書き出せます。URLや端末を変える際は、先に書き出して新しい環境へ読み込んでください。ゲームからセーブや分析情報を作者へ自動送信する機能はありません。

内容・数値は調整中です。初見での所要時間、投資や戦闘の構成の面白さ、操作の面倒な箇所をテストしていただく段階です。不具合の報告時は、バージョン・世代・波・直前の操作をお伝えください。

このリポジトリにはブラウザーへ配布するゲームファイルを置いています。
