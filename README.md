614件の逐次テスト、21条件160人生の実獲得進行、隔離ブラウザーで保存/再読込/2タブ・製作/自動調理の時間停止・画面幅320/390/1280を確認。公開時も実ユーザー保存を操作しません。

保存は端末のブラウザー内です。更新前の保存ファイルは保存メニューから書き出せます。実機タッチ・実音・人間の面白さは自動検証とは別です。
