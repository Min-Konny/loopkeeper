# LoopKeeper: Idle Defense 0.6.11

公開先: https://min-konny.github.io/loopkeeper/?v=0.6.11

- 素振り・防御・体力は「この命の進行Lv.○まで」で予約。到達すると次へ進み、到達済みは時間を使わず省略します。
- 目標は右側の予約列と予約編集で変更でき、保存・再読込・保存した手順に保持。既存の回数予約と採集・製作の回数指定は維持します。
- 行動予約をWAVE1撃破で無料解放。最高WAVE1以上の旧セーブも再読込で使え、転生やリセットは不要です。
- 上部の常設所持品・次の敵のステータス・広いPC作業欄・野営地を保持。継承の配分時期とゲームバランスの追加調整は別途進めます。

既存の保存・所持品・本編進行を保持します。保存データは端末のブラウザー内にあります。
