# LoopKeeper: Idle Defense 0.6.5

公開先: https://min-konny.github.io/loopkeeper/?v=0.6.5

- 拡大表示の上部にも「予約」を追加し、編集・追加・並べ替えへ直接進めます。閉じると元の拡大表示へ戻ります。
- 上部の「予約」は常に編集画面を開きます。停止理由の通知と、予約を編集する入口を分けます。
- 予約編集画面から停止理由を確認し、実行可能なら再開できます。停止理由の自動ポップアップは維持します。
- 未解放時の説明を「W2突破で無料解放」に修正します。ゲームバランス・セーブ形式は変更しません。

既存の保存・所持品・本編進行を保持します。保存データは端末のブラウザー内にあります。

設定とメニューは通常表示・拡大表示の上部から開けます。予約は上部から編集できます。焚き火は既存アセットをコンパクトに復帰し、動き軽減設定を引き継ぎます。反映のためにセーブ削除や転生は不要です。
