# LoopKeeper: Idle Defense 0.6.7

公開先: https://min-konny.github.io/loopkeeper/?v=0.6.7

- 幅1000px以上では、左の作業メニューを選んでも通常画面内で切り替えます。右の予約列と野営地を見たまま操作できます。
- 広い画面の作業用の拡大入口を整理します。狭幅では従来の拡大表示を利用できます。設定・確認・停止通知は維持します。
- 拡大中に画面を広げたときは、選択タブ・作業内容・予約を保って通常表示へ戻します。設定などを開いている場合も不意に閉じません。
- ゲームバランス・保存形式は変更しません。再読み込みで反映され、セーブ削除や転生は不要です。

既存の保存・所持品・本編進行を保持します。保存データは端末のブラウザー内にあります。

広いPC画面（幅1000px以上）では左メニューの選択を通常画面内で切り替え、右の予約列と野営地を維持します。狭幅は従来の作業拡大を利用できます。幅変更で設定・確認ダイアログを閉じず、作業の入力・タブ・予約・スクロールを保持します。
