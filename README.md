# LoopKeeper: Idle Defense

資源を集め、村と装備を強化し、自動戦闘で襲撃を迎え撃つ周回型ゲーム。

[ゲームを遊ぶ](https://min-konny.github.io/loopkeeper/?v=0.3.8)

## 0.3.0
- 7施設を各5段階へ強化。設備投資の素材費と解放時期を調整。
- 段階式装備強化、釣りと調理、防御・体力訓練、飛行敵と弓塔。
- 素材充足表示、発見・資源・施設支援の演出、保存手順プレビュー。
- クリア世代数のPNG保存。

保存はブラウザーごとです。データの保存から書き出し・読み込みができます。進行中の旧周回の敵数値は維持し、次の周回から新調整を適用します。

## 0.3.1
未返答の外交要請と期限を全タブで表示。残り30秒で強調し、返答するボタンから外交へ移動できます。

## 0.3.2
自動調理の消費素材・食料生産量・補充目標と動作状況を表示。

## 0.3.3
裏画面への移動時に停止するかをゲーム設定で選択可能に。初期設定は停止しない。ゲームを閉じた間は進みません。

## 0.3.4
設定を上部の歯車ボタンへ分離。裏画面の自動停止・音量・演出を専用画面で変更できます。

## 0.3.5
自動調理の操作を工房上部へ移動し、補充目標・開始・不足理由を表示。人員を独立タブに分離。救護所と衛兵詰所の建設・強化で薬草を消費。保留予約が調理用素材を取り置く不具合を修正。

## 0.3.6
人員の作業先・自動作成の個数・補充目標などの入力中も、ゲームを自動停止しないように変更。
転生時に同じ継承候補で死亡画面が残る不具合を修正。

## 0.3.7
上部の履歴アイコン・左下の版番号から更新履歴を確認できる画面を追加。

## 0.3.8
加工職人の操作を工房上部へ移動。加工品・補充目標・ON/OFF・強化と進行状況・停止理由を表示。
