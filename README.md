# LoopKeeper: Idle Defense 0.6.23

公開先: https://min-konny.github.io/loopkeeper/?v=0.6.23

- 0.6.22のピクセル野営地・採掘/釣り/訓練・戦闘背景を維持しました。
- 予約の目標レベル・回数は入力中の下書きとして保持し、入力確定またはEnterで反映します。途中の数字で停止通知に移る不具合を修正しました。
- Escapeで入力を取り消し、次のEscapeで画面を閉じます。取消後に時間が進んでも古い回数を再保存せず、実行済みの進行を巻き戻しません。
- 削除・置換済みの予約へ古い入力を適用しません。ゲーム数値・保存形式を維持し、再読込で反映されます。

既存の保存データを維持します。セーブ削除や転生は不要です。
