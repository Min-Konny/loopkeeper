# LoopKeeper: Idle Defense 0.6.1

公開先: https://min-konny.github.io/loopkeeper/?v=0.6.1

- 加速中でも、作業や有効な予約などがなければ時間と加速残量を止めます。明示的な待機と戦闘は進みます。
- 寄り道の勝利・撤退・敗北・時間切れ後は、実行可能な予約や作業を再開。手動停止と素材・技能不足時の停止は維持します。
- 鉄に「材料が尽きるまで連続」と停止ボタンを追加。途中の支払いを保持し、再読込や別タブ移動では連続を解除します。
- 継承を戦闘・生産・交易・自動化/人員などのジャンル別に表示します。
- 拡大メニューを外側クリック・タップで閉じられます。内部操作やスクロール、ドラッグでは閉じません。

既存の保存・所持品・本編進行を保持します。保存データは端末のブラウザー内にあります。
