# LoopKeeper 0.6.113

ゲーム: https://min-konny.github.io/loopkeeper/

0.6.50の表示改善：拠点の背景・工房・木こりと、序盤の狼戦を表示専用Phaserで描画します。管理画面は従来のDOMを維持し、資源・戦闘計算・自動化・保存・バランスは変更しません。工房の建築変化、木こりの往復・伐採・運搬、戦闘の踏み込み・被弾を描画します。既存10施設の種類・段階・増築数は景観と凡例に反映します。

演出OFF・縮小モーション・読込失敗時も管理と進行を継続できます。設定の「使用ライブラリとライセンス」から同梱コードの通知を確認できます。オリジナル生成素材の出所・履歴は assets/pixel-v2/ARTWORK-PROVENANCE.json に収録。Phaser 3.90.0と内包コードの通知を同梱しています。

0.6.51: 伐採・採掘・鍛冶の独自アクション絵と進捗に連動した動き、未制作装備・施設の次段階と不足材料、継承の実効時間と0.25秒下限の案内を追加。資源・戦闘・保存・バランスの計算は変更しません。

0.6.52: 第6波突破後の通常準備中に、確認して次の襲撃を迎えられます。飛ばした準備時間の収益・作業成果・回復は得られません。待機と通常の自動襲撃も選べます。保存失敗時は戦闘を始めません。採取継承の数値調整は未採用・未解決です。


0.6.53: 採集の技法に、通常装備・建築の木石・金属・獣皮の材料節約を追加。累計1/3/6/10/15ptで2/6/12/20/20%、既存整数費用から切上げ・最低1。金・食料・薬草・職人の産出・加工/消耗品/装飾品・柵追加強化は対象外。本人の採集速度と0.25秒下限は従来どおり。継承画面に現在/次の節約と実費用例を表示し、未払い作業だけに適用します。振り直しは従来どおり転生準備中のみです。


0.6.54: 魚料理の自動調理中も保存・再読み込みできるよう、既存の料理一覧に保存検証を合わせました。支払済み材料と調理進捗を維持します。経済・戦闘・料理の数値は変更していません。

### 開発用の投資回帰チェック

Node.js 24以降で `node --test tests/investment-facility-sum.test.mjs` を実行できます。施設段階17/18/19、追加柵強化の除外、停止条件、保存再読込と数値資料の一致を確認します。合成状態はテスト内だけで作り、実セーブやテスト用の書き出しデータは含めません。

version2の村への投資は、準備中15ゲーム秒ごとに通常施設段階合計×0.5金。合計18の上限はなく、追加柵強化は数えません。所持金の既存上限は1e9です。旧version1の施設数×1金/10秒・戦闘中も収入という仕様とは区別します。今回訂正したのは古い開発補足のみで、収入計算・ゲームバランス・保存形式・ゲーム版数0.6.57は変更していません。
