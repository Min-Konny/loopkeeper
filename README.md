# LoopKeeper: Idle Defense 0.6.3

公開先: https://min-konny.github.io/loopkeeper/?v=0.6.3

- 襲撃時計を1箇所に整理し、停止・再開を直接操作できます。加速はヘッダーメニューへ移しました。
- 食料・金貨・現在の主産物を残し、その他の在庫はバッグの4分類から確認できます。レシピの必要数・所持数はカードに残ります。
- 課題はヘッダーから確認でき、新しい達成をバッジで知らせます。報酬は従来どおり自動反映です。獲得済み方針と連携は詳細にまとめました。
- 予約の停止理由は停止時に一度表示し、閉じても停止を保ちます。ヘッダーから再確認し、必要な操作で再開できます。
- 左ナビから対象メニューを直接拡大し、拡大画面で別メニューへ切り替えられます。外側クリック・ESC・フォーカス復帰を改善しました。

既存の保存・所持品・本編進行を保持します。保存データは端末のブラウザー内にあります。
