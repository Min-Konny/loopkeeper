# LoopKeeper: Idle Defense

資源を集め、村と装備を強化し、自動戦闘で襲撃を迎え撃つ周回型ゲーム。

[ゲームを遊ぶ](https://min-konny.github.io/loopkeeper/?v=0.3.1)

## 0.3.0
- 7施設を各5段階へ強化。設備投資の素材費と解放時期を調整。
- 段階式装備強化、釣りと調理、防御・体力訓練、飛行敵と弓塔。
- 素材充足表示、発見・資源・施設支援の演出、保存手順プレビュー。
- クリア世代数のPNG保存。

保存はブラウザーごとです。データの保存から書き出し・読み込みができます。進行中の旧周回の敵数値は維持し、次の周回から新調整を適用します。

## 0.3.1
未返答の外交要請と期限を全タブで表示。残り30秒で強調し、返答するボタンから外交へ移動できます。
