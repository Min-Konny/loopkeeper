# LoopKeeper: Idle Defense 0.6.27

公開先: https://min-konny.github.io/loopkeeper/?v=0.6.27

- 継承配分で確定済みと配分後の効果を並べて確認できます。生存中の配分制限と次の命への反映は従来どおりです。
- 外交の援助依頼を先に表示し、任意の契約と交易路を整理しました。
- 上部に通常資源のアイコンと数量を表示します。名前はホバー・フォーカス・タップで確認でき、永久素材はバッグとアクセサリー画面から確認できます。
- 採集カードの高さと予約操作を整え、配分画面の再描画でもキーボードのフォーカスを保持します。最新のピクセルアート、ゲーム数値、保存形式を維持しています。

既存の保存・獲得品・本体進行を維持します。保存データは端末のブラウザー内にあります。
