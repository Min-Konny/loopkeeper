# LoopKeeper: Idle Defense 0.6.28

公開先: https://min-konny.github.io/loopkeeper/?v=0.6.28

- 今行ける寄り道を先に表示し、危険度・条件・主な報酬を比べやすくしました。出発はカードから直接行えます。
- 敵の詳しい数値と攻略文、これから開く道、今の命でクリア済みの道を折りたたみ、作業スペースを広く保ちます。
- 帰還結果から次の行動へ進みやすくしました。予約があれば再開し、行動がなければ時間を止める既存の動作を維持しています。
- 敵・報酬・解放条件・保存形式と最新アート、0.6.27のUI改善を維持しています。

既存の保存・獲得品・進行を維持します。保存データは端末のブラウザー内にあります。
